Vivid, color-intensive theme for Visual Studio (2022/2026) with a consolidated color code for all programming languages.

## Themes
1. **Hiberbee Dark** - my improvements (colored extension methods, enum values, etc.)
2. **Hiberbee Legacy** - the original JetBrains-version colors
3. **Hiberbee Light** - light version

## Features
- Unique color identity map for all language elements and constructs.
- Design is available and maintained in the Figma [template](https://www.figma.com/file/2oyhOnKUdLZCDQEkH2klNT/Hiberbee-Theme) color palette.

## Download Latest Version
The latest stable version can be downloaded from the Visual Studio [marketplace][marketplace] page.

## How To Use
1. Download the latest version of the extension from Visual Studio marketplace (.vsix file), or install it via **Extensions > Manage Extensions**.
2. Restart Visual Studio.
3. Choose the theme: **Tools > Theme > Hiberbee**.

## Font
The font in the screenshots differs from the Visual Studio default. To get the same look, [download](https://www.jetbrains.com/lp/mono/) and install the JetBrains fonts, then go to **Tools > Options > Environment > Fonts and Colors** and select JetBrains Mono in the Font field.

## Build
 - `make.bat` - restore and build the Release configuration.
 - `clean.bat` - remove build artifacts.
